Snippet actions

The same short Option::or_value() example, with six ways to arrange its actions. Every example can be run and edited.

Inset buttonsFooter stripCaption toolbarText actionsIcons with labelsIcon-only toolbar

Evenly inset buttons

Keep the familiar buttons, with the same space above and below the action row.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Footer strip

Give the controls a clearly defined row, separate from the code.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Caption toolbar

Put small, quiet controls beside the title. This leaves more room for the example.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Text actions

Keep actions below the code, with less visual weight and labels aligned with the code.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Icons with labels

Pair the familiar labels with small line icons. The action still reads clearly without knowing the symbol.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Icon-only toolbar

Keep controls in the caption bar. Hover or focus for the action name; Edit becomes Reset after editing.

Example 
Some(1).or_value(5) //-> 1
None.or_value(5) //-> 5

Source listing

The source listing stays read-only, as on the method page.

Source Code 
public method or_value<T>(this: Option<T>, value: T): T {
  match this {
    Some(v) => v,
    None => value
  }
}

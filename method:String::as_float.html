String::as_float()

Parse this string as a floating point number, returning Some if successful. Decimal and exponent notation are supported. Leading and trailing whitespace are not accepted.

Example
"12.5".as_float() //-> Some(12.5)
"1e3".as_float() //-> Some(1000.0)
"abc".as_float() //-> None

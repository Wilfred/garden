Path::join()

Append component to this path, inserting / if needed. If this path is empty, return component unchanged. An absolute component (starting with /) replaces this path.

Example
Path{ p: "" }.join("file") //-> Path{ p: "file" }
Path{ p: "dir" }.join("file") //-> Path{ p: "dir/file" }
Path{ p: "/tmp" }.join("/etc/config") //-> Path{ p: "/etc/config" }
Source Code
public method join(this: Path, component: String): Path {
  if this.p == "" || component.starts_with("/") {
    return Path{ p: component }
  }

  let p = if this.p.ends_with("/") {
    this.p ^ component
  } else {
    (this.p ^ "/") ^ component
  }

  Path{ p: p }
}
